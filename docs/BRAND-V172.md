# Brand foundation v172

The visible product is still **RareWorth**. No rename, logo, domain, repository,
backend or storage migration is part of this release.

## Brand source and presentation

`brand-v172.js` exposes the frozen, non-writable, non-configurable
`window.RareWorthBrand`. It loads before the existing scripts and fills title,
topbar name/tagline, onboarding name/title, settings eyebrow, About name/tagline/
version/accessibility label and the hidden scanner introduction at DOMContentLoaded.
Existing global APIs are never replaced. There are no dependencies, storage calls
or network requests. The existing script order and launch-gate logic remain intact.

## Explicit branding exceptions

The production hardcoding allowlist is `tests/brand-allowlist-v172.json`. Each entry
is an exact matching source line, including multiplicity; a new or changed brand
literal fails the test. It covers only files that actually contain brand strings.
Production files are tracked files outside tests/docs/scripts/data/.github, excluding
Markdown and patches. Binary content is not treated as source text.

- `brand-v172.js`: canonical values and the stable API identifier.
- `index.html`: static no-JS/title/metadata/accessibility fallbacks. Keep these in
  sync with config during a later rebrand. Existing layout stays unchanged.
- `ui-v150-experience.js`: the dynamically rendered `RareWorth · JP` artwork
  placeholder is an explicit presentation exception; its shared engine is untouched.
  Update this copy in a separately reviewed rebrand change.
- `manifest.json`, `icon-rareworth.svg`: install metadata and existing logo title.
- All other entries: stable API names, storage/backend identifiers, cache names,
  asset paths or internal comments. They are not automatic rename targets.

## Future manifest/metadata checklist

Change `manifest.json` fields `name`, `short_name`, `description`; change `icons`
only if a separately approved new icon is supplied. Update HTML
`apple-mobile-web-app-title`, static `<title>`, and config `appTitle`/`shortName`.
Review HTML `theme-color` and manifest `theme_color`/`background_color` only when
brand colours change. Check icon SVG accessibility title and install icon paths.
Preserve `start_url`, scope, URLs, display and orientation. Installed OS labels may
update on a different schedule from the document title. Bump the shell cache and
affected asset query keys; never unregister the worker or cache external assets.

migration history and auth URL configuration remain unchanged. Do not put backend
configuration in the brand object. GitHub repository/project naming and Pages URLs
are also independent of the visible app name; no remote rename is performed.
