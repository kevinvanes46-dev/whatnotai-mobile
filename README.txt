WhatnotAI Mobile Standalone v35

Dit is de telefoon-versie zonder pc-server.

Bestanden:
- index.html
- style.css
- app.js
- data/cards.json

Gebruik op pc:
1. Open mobile_app/index.html in je browser.

Gebruik op mobiel zonder pc aan:
Beste manier:
1. Zet de map mobile_app online via GitHub Pages, Netlify of een simpele webhost.
2. Open de link op je telefoon.
3. Voeg eventueel toe aan beginscherm.

Lokaal op telefoon kan ook, maar iPhone/Android blokkeren soms JavaScript/clipboard bij losse bestanden.
Online via GitHub Pages werkt meestal het soepelst.

Voorbeelden snelinvoer:
- jp base 002 ivysaur nm
- jp fossil 094 gengar nm
- jp neo revelation 220 swinub nm
- en neo revelation 57 swinub nm
- en delta charizard 4 nm

Let op:
- JP vintage gebruikt aparte Cardmarket pagina's, bijvoorbeeld Expansion Pack voor JP Base.
- De app toont geen live lowest-prijs in de app. Hij bouwt de juiste Cardmarket-link.
- Gratis, geen OpenAI API, geen OCR, geen server nodig.
