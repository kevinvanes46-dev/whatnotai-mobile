CardScout v100 CORE3 STABLE — internal regression evidence
Date: 2026-08-09

Scope
The scanner is intentionally limited to THREE outputs only:
1. card name
2. collector/card number
3. set
No attack text, rules text, HP/body OCR, price OCR, or automatic 1st Edition OCR.

Architecture checks
PASS - guided camera geometry restored to v77 behavior
PASS - yellow-border auto-crop is NOT applied to guided camera captures
PASS - gallery-only yellow-border auto-crop retained
PASS - exactly 2 Tesseract worker.recognize() calls in the entire app
PASS - no full-card OCR call
PASS - top OCR composite contains title/header area only
PASS - bottom OCR composite contains collector/set-number strip only
PASS - exact local DB evidence outranks fuzzy OCR/set-symbol guesses
PASS - JavaScript syntax check (node --check)
PASS - failed/incomplete scans are recorded locally and exportable as JSON

Important limitation
The archived chat screenshots are lower resolution than the original iPhone camera photos. A result that is marginal on an old screenshot can be materially better on the original capture. The release therefore does not claim 100% recognition on every Pokemon printing. It does guarantee that the scanner no longer reads unrelated attack/body text and that failed cases are captured in a structured debug export instead of being silently guessed.
